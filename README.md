# 声场 · Voice Foundry Local

声场是一个在 Windows 本机运行的语音工作室。你可以用文字设计声音，用有授权的录音创建音色，再给台词、视频或整本书配音。浏览器、命令行和其他软件共用同一套模型和音色，不需要在每个项目里重新安装。

目前接入 VoxCPM2，提供中文界面、深浅配色和本地 HTTP API。平台与游戏引擎无关，也可以用于有声读物、影视配音和交互应用。

## 安装

目前主要在 Windows 11、RTX 4090 上验证。需要 Git、[uv](https://docs.astral.sh/uv/getting-started/installation/) 和可用的 NVIDIA 驱动。FFmpeg 需单独安装，用于格式转换、后处理和高级音频处理；仓库不附送它的程序。

下载源码后，在项目目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\install.ps1
```

脚本会建立独立的 Python 3.11 环境，安装依赖，从官方来源下载固定版本的模型，再运行核心测试并启动服务。第一次安装需要联网；模型和运行环境会占用数 GB 磁盘，下载缓存还会额外占用空间。配音和录音处理在本机完成。

安装完成后，打开 [本机工作室](http://127.0.0.1:8961/)。以后双击 `启动语音平台.cmd` 即可，停止用 `停止语音平台.cmd`。关掉网页不会取消后台任务。详细步骤见 [安装说明](docs/INSTALL.md)。

公开仓库没有模型权重、参考录音、个人音色、数据库或预装环境。

## 先完成一段配音

1. 打开“语音生成”，输入文本。没有音色时，可以先用文字描述想要的声音。
2. 生成后试听。需要重做时，修改描述或生成多个候选再比较。
3. 确认满意后批准，并在试听页选择格式导出。

生成成功的音频仍然是待审核状态。批准由使用者试听后完成，平台不会把模型输出自动当成正式素材。

## 创建和复用人物音色

“快速创建参考”提供一条完整流程：上传录音，自动处理、切分并推荐片段，试听后保存到音色库。原始录音会保留，处理前后可以比较。转写也会自动生成，使用极致克隆前请先校对。

同一个人物可以保存多个片段，选一个主参考，也可以保留不同场景的参考。生成时使用其中一个片段，不会把它们直接拼成长录音。稳定的 Voice ID 可以跨项目复用，也可以设置项目专属音色。

可控克隆允许参考音色配合风格描述；极致克隆使用参考录音和准确转写。情绪、语气和语速的自然语言控制只能近似引导，仍需试听。去音乐、降噪和双路人声分离也可能留下残留、失真或串音。

## 给长文和整本书配音

“长文配音”支持 TXT、Markdown，以及 UTF-8、UTF-16、GB2312、GBK、GB18030 等编码。导入后按章节和段落组织；没有章节或没有换行的文本也会自动拆分。

可以暂停后继续、重试失败段、逐章试听审核，再按章节或整本导出。界面分页读取内容，避免把全书塞进普通任务队列。超长文本的导入和索引，与整本音频生成的耗时是两回事；生成仍受文本长度、模型速度和硬件影响。操作见 [长文说明](docs/LONGFORM.md)。

## 从命令行或其他软件调用

```powershell
bin\voice.cmd start
bin\voice.cmd generate --text "欢迎来到新的世界。" --style "沉稳成年男性，温暖自然" --wait
bin\voice.cmd voices
bin\voice.cmd health
```

需要全局命令或 Codex MCP 时，按 [安装说明](docs/INSTALL.md)执行可选注册。WebUI 不依赖 Codex，API 也不依赖浏览器。服务启动后可查看 [OpenAPI 文档](http://127.0.0.1:8961/docs)。

## 文件和维护

模型放在 `models/`，用户资产和数据库放在 `data/`，缓存与日志放在 `runtime/`。具体路径统一在 `config/platform.json` 配置。导出会另存文件，后处理不覆盖原始生成音频。

已结束任务默认 7 天后归档，也可以手动批量归档。管理页的删除进入可恢复的回收站，不会直接清空磁盘文件。备份与恢复见 [维护说明](docs/MAINTENANCE.md)。
