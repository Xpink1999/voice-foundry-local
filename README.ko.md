# Voice Foundry

Windows에서 목소리를 디자인하고 녹음으로 음성을 복제해 대사, 영상, 책의 음성을 제작하는 로컬 서비스입니다. WebUI, CLI, REST API, MCP가 같은 모델과 목소리 라이브러리를 사용하므로 프로젝트마다 다시 설치할 필요가 없습니다.

현재 엔진은 VoxCPM2입니다. 화면은 중국어, 영어, 일본어, 한국어와 밝은 테마·어두운 테마를 지원하며 브라우저 설정을 따를 수 있습니다. 화면 언어와 음성 언어는 따로 선택합니다. 본문, 에셋 이름, 전사문은 원문을 유지합니다. 게임, 영상, 오디오북, 대화형 앱에서 독립적으로 사용할 수 있습니다.

## 설치

주요 검증 환경은 Windows 11과 RTX 4090입니다. Git, [uv](https://docs.astral.sh/uv/getting-started/installation/), 정상 작동하는 NVIDIA 드라이버가 필요합니다. 형식 변환, 후처리, 고급 오디오 처리에는 [FFmpeg](https://ffmpeg.org/download.html)를 별도로 설치하세요.

소스를 내려받은 뒤 프로젝트 폴더에서 실행합니다.

~~~powershell
powershell -ExecutionPolicy Bypass -File .\scripts\install.ps1
~~~

스크립트는 독립된 Python 3.11 환경을 만들고 의존성과 고정 버전 모델을 설치한 뒤 코어 테스트를 실행하고 서비스를 시작합니다. 처음 설치할 때는 인터넷 연결이 필요합니다. 모델과 환경에 수 GB, 다운로드 캐시에 추가 공간이 필요합니다. 음성 생성과 녹음 처리는 로컬에서 실행됩니다.

[WebUI](http://127.0.0.1:8961/)를 엽니다. 다음부터는 `start-voice.cmd`로 시작하고 `stop-voice.cmd`로 종료합니다. CLI 사용법은 [설치 안내](docs/INSTALL.ko.md)에 있습니다. 브라우저를 닫아도 백그라운드 작업은 취소되지 않습니다.

공개 저장소에는 모델 가중치, 참조 녹음, 개인 목소리, 데이터베이스, 설치된 실행 환경이 포함되지 않습니다.

## 생성과 검토

1. '음성 생성'에서 텍스트를 입력합니다. 저장한 목소리가 없으면 원하는 목소리를 글로 설명합니다.
2. 생성 결과를 듣습니다. 비교가 필요하면 같은 텍스트로 여러 후보를 생성합니다.
3. 직접 듣고 승인한 뒤 재생 화면에서 형식을 선택해 내보냅니다.

생성 결과는 검토 대기 상태로 저장됩니다. 음성을 자동으로 승인하지 않습니다.

## 목소리와 참조 녹음

빠른 참조 만들기는 업로드, 처리, 분할, 구간 추천을 한 흐름으로 제공합니다. 구간을 들어 본 뒤 목소리 라이브러리에 저장합니다. 원본 녹음을 보존하며 처리 전후를 비교할 수 있습니다. 전사문은 자동으로 생성되므로 Hi-Fi 복제에 사용하기 전에 교정하세요.

한 인물에 여러 참조 구간을 저장하고 기본 참조와 장면별 참조를 지정할 수 있습니다. 생성할 때는 한 구간을 사용하며, 여러 구간을 긴 녹음으로 단순 연결하지 않습니다. 목소리에는 전역 Voice ID가 있으며 프로젝트 간 공유하거나 특정 프로젝트 전용으로 설정할 수 있습니다.

제어형 복제는 참조 목소리와 스타일 설명을 함께 사용합니다. Hi-Fi 복제는 참조 녹음과 정확한 전사문을 사용합니다. 자연어로 지정한 감정, 말투, 속도는 근사적인 유도이므로 직접 들어서 확인해야 합니다. 배경 음악 제거, 잡음 제거, 두 화자 음성 분리에는 왜곡, 잔여 소리, 다른 목소리의 혼입이 생길 수 있습니다.

## 장문 음성 제작

TXT, Markdown과 UTF-8, UTF-16, GB2312, GBK, GB18030 인코딩을 지원합니다. 가져올 때 장을 인식하고 구간을 나눕니다. 제목이나 줄바꿈이 없는 텍스트도 자동 분할합니다.

일시 정지와 이어서 작업, 실패 구간 재시도, 장별 재생·검토, 장별 또는 전체 내보내기를 지원합니다. 내용은 페이지 단위로 읽습니다. 대용량 텍스트의 가져오기·색인 검증이 전체 음성 생성 완료를 뜻하지는 않습니다. 생성 시간은 텍스트 길이, 모델, 하드웨어에 따라 달라집니다. [장문 안내](docs/LONGFORM.ko.md)를 참고하세요.

## CLI와 API

~~~powershell
bin\voice.cmd start
bin\voice.cmd generate --text "이 문장은 음성 샘플입니다." --style "차분한 성인 남성, 따뜻하고 자연스러운 목소리" --wait
bin\voice.cmd voices
bin\voice.cmd health
~~~

[전역 명령과 MCP](docs/INSTALL.ko.md#전역-명령과-mcp)는 선택 사항입니다. WebUI는 Codex 없이, API는 브라우저 없이 사용할 수 있습니다. 서비스가 실행 중일 때 [OpenAPI 문서](http://127.0.0.1:8961/docs)를 확인할 수 있습니다.

## 파일과 유지 관리

모델은 `models/`, 에셋과 데이터베이스는 `data/`, 캐시와 로그는 `runtime/`에 저장합니다. 경로는 `config/platform.json`에서 설정합니다. 내보내기는 별도 파일로 저장하며 후처리가 원본 음성을 덮어쓰지 않습니다.

완료된 작업은 기본적으로 7일 뒤 보관되며 수동 일괄 보관도 가능합니다. 관리 화면에서 삭제한 항목은 복구 가능한 휴지통으로 이동하며 디스크 공간이 즉시 확보되지는 않습니다. 아래 상세 문서는 중국어입니다.
