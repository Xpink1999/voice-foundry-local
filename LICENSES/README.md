# 这些文件是什么

这里保存第三方许可资料，不含模型权重或程序二进制。

- `upstream/`：平台用到的推理仓库许可证，来自固定提交。
- `models/`：实际使用版本的原始模型卡。标注“模型卡声明”的地方，没有替上游另写授权。
- `python/`：运行环境中 Python 包附带的许可和第三方声明。少数 wheel 未附带正文的包，补存了对应上游版本的许可。
- `python-dependencies.json`：包名、版本、许可说明和文件哈希。
- `source-records.json`：从上游补取文件的地址、修订和哈希。

这些文件保持上游原文。它们不受平台自身的 Apache-2.0 许可重新授权。更新依赖或模型时，要同时检查对应的许可和来源记录。
