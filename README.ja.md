# Voice Foundry

Windows 上で音声をデザインし、録音から音色を作り、台詞・動画・書籍を音声化するローカルサービスです。WebUI、CLI、REST API、MCP が同じモデルと音色ライブラリを使用するため、プロジェクトごとの再インストールは不要です。

現在のエンジンは VoxCPM2 です。画面は中国語・英語・日本語・韓国語に対応し、ライト／ダークテーマとブラウザー設定への追従を選べます。画面と音声の言語は別々に選択します。本文、素材名、文字起こしは原文を保持します。ゲーム、映像、オーディオブック、対話型アプリで独立して使用できます。

## インストール

完全な音声生成には Windows 11、Git、[uv](https://docs.astral.sh/uv/getting-started/installation/)、利用可能な NVIDIA ドライバーが必要です。主に RTX 4090 で検証しています。録音のアップロードと処理には [FFmpeg](https://ffmpeg.org/download.html) も必要です。Python や Codex の事前導入は不要です。

GitHub で **Code → Download ZIP** を選んですべて展開し、`install-voice.cmd` があるフォルダーで同ファイルを実行します。PowerShell でも実行できます。

~~~powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\install.ps1
~~~

完全版は専用環境、固定版ソースとモデルを取得し、確認後に起動します。30 GiB 以上の空きを推奨します。画面だけを確認する場合は `-CoreOnly -NoStart` を付けてください。CUDA とモデルは取得せず、音声生成はできません。

[WebUI](http://127.0.0.1:8961/) で声を説明して一文を生成できます。保存済み音色や録音は不要です。以後は `start-voice.cmd` と `stop-voice.cmd` を使います。取得手順、依存関係、ポート競合、問題解決は[インストール手順](docs/INSTALL.ja.md)を参照してください。

ソースの配布物にはモデルの重み、録音、データベース、インストール済み環境は含まれません。

## 生成と審査

1. 「音声生成」でテキストを入力します。保存済みの音色がなければ、声の特徴を文章で指定します。
2. 生成結果を試聴します。比較したい場合は、同じテキストで複数の候補を生成します。
3. 試聴して承認した後、試聴画面で形式を選び、書き出します。

生成結果は審査待ちになります。音声が自動承認されることはありません。

## 音色と参照録音

クイック参照作成では、録音のアップロード、処理、分割、候補の推薦をまとめて行えます。試聴してから音色ライブラリに保存します。元の録音を保持し、処理前後を比較できます。文字起こしは自動生成されるため、Hi-Fi クローンに使う前に修正してください。

一人の人物に複数の参照クリップを保存し、主参照や場面別の参照を設定できます。生成には一つのクリップを使用し、長い録音へ単純に連結しません。音色にはグローバル Voice ID があり、プロジェクト間で共有するか、特定のプロジェクト専用にできます。

制御可能クローンは参照音色とスタイルの説明を組み合わせます。Hi-Fi クローンは参照録音と正確な文字起こしを使用します。文章による感情、口調、速度の指定は近似的な誘導なので、試聴で確認してください。音楽除去、ノイズ除去、二人の声の分離には、歪みや残留音、他の声の混入が生じることがあります。

## 長文の音声化

TXT、Markdown と UTF-8、UTF-16、GB2312、GBK、GB18030 に対応します。取り込み時に章を検出して分割します。見出しや改行のない文章も自動分割できます。

一時停止と再開、失敗した区間の再試行、章ごとの試聴・審査、章単位または全巻の書き出しに対応します。内容はページ単位で読み込みます。大容量テキストの取り込み・索引作成の検証は、全巻の音声生成完了を意味しません。生成時間は文章量、モデル、ハードウェアによって変わります。[長文ガイド](docs/LONGFORM.ja.md)を参照してください。

## CLI と API

~~~powershell
bin\voice.cmd start
bin\voice.cmd generate --text "これは音声のサンプルです。" --style "落ち着いた成人男性、温かく自然な声" --wait
bin\voice.cmd voices
bin\voice.cmd health
~~~

[グローバルコマンドと MCP](docs/INSTALL.ja.md#グローバルコマンドと-mcp)は任意の設定です。WebUI は Codex なしで、API はブラウザーなしで使用できます。サービス起動中は [OpenAPI ドキュメント](http://127.0.0.1:8961/docs)を参照できます。

## ファイルと保守

モデルは `models/`、素材とデータベースは `data/`、キャッシュとログは `runtime/` に保存します。パスは `config/platform.json` で設定します。書き出しは別ファイルに保存し、後処理で元の音声を上書きしません。

終了済みタスクは標準で 7 日後にアーカイブされ、手動での一括アーカイブも可能です。管理画面で削除した項目は復元可能なごみ箱へ移動し、直ちにディスク容量が空くわけではありません。以下の詳細資料は中国語です。
