# VoiceStudio 对照与工作流改造

对照日期：2026-10-27。Voice Foundry 基线为 c7a0672；本地 VoiceStudio 为 776460f510c127ebe62125554f478639e8cdd293，比外部方案中 d5ebe9a 更新。此文记录源码证据和落地选择；真实声音质量单独验收。没有复制 VoiceStudio 源码、迁移前端框架或改变本项目许可。

## 对照结果

| 工作流 | VoiceStudio 的做法及源码 | 声场原有阻断 | 本次修改 |
|---|---|---|---|
| 人物选择与配音 | clone-page.tsx 根据 choosingVoice / savingUpload / hasVoice 互斥呈现；reference-panel.tsx 保存后选中人物 | 先理解片段、参考、人物三种对象，入库后自己找绑定入口 | 片段保存后留在原流程设置人物，成功后直接带入工作台 |
| 录音候选选择 | speaker_clone.py 从可用同人片段提取参考，拒绝启发式身份 | radio 保存人物与 checkbox 入库并存，文案还需解释控件形状 | 一套多选；人物阶段才明确选默认参考；同名人物不自动合并 |
| 多段短句 | speaker_clone.py 保留文本对应关系，短片段可汇集 | 本平台只有自由试听合并，不能直接入库 | 自由试听和受控复合参考分开；同人、授权、去重、独立人声门槛、最终转写、人工确认后入库 |
| 逐句纠错 | dub-page.tsx、segment-find.ts 支持生产文本编辑 | 只能换参考重做，错字要回原文件 | 普通和长文重做支持本次文本修订；原文、旧音频和旧配置不覆盖 |
| 问题定位 | transcript-issue-navigation.tsx 保持问题顺序与当前位置 | 长文靠章节和分段分页查找 | 持久问题清单、跨章分页定位、解决后仍需人工审核 |
| 重做恢复 | render-recovery.tsx 回到已存在任务，不重新提交 | 普通重做关闭后难以找回关联结果 | 原候选可查询重做任务，重开恢复进度与新版试听 |
| 模型可用性 | use-tts-readiness.ts 区分后端、引擎和完整权重 | 支持能力不等于本机安装完整，提交后才报错 | 模型就绪信息和提交前文件检查；未加载不视为缺模型 |
| 事件和导出 | backend/core/tasks.py 持久事件序号、after_seq | 全历史事件轮询，导出等待同步请求 | 任务索引增量查询、游标恢复、普通后台导出、幂等和取消 |

VoiceStudio 的多模型数量、页面说明或局部测试不能证明它的中文音质、人物分离或全部界面已经优于声场。借鉴的是对象交接、编辑上下文和恢复方式。声场的原件保留、逐版本审核、项目隔离、独立片段、授权记录和可追溯导出继续保留。

## 操作原则

- 当前阶段只做一个决定：选片段，随后设置人物，最后写台词。
- 保存后显示持续可操作的下一步，不只发短暂提示。
- 试听不改变选中项；提交只读取明确勾选。
- 支持能力、资源可用、运行成功和人工试听批准分开显示。
- 失败不清空草稿或已有结果。刷新先查询已有任务。
- 推进长文生产不以全部生成成功替代问题解决和逐章审核。

## 仍需独立验证的边界

三人重叠适配器接入的是原生三人候选，不是更改双人参数。候选未在本机安装并通过中文录音试听，不能写成三人音质通过。8 kHz 输出的频带限制明确保留。人物跟踪、分离和转写均可能出错，新的修正流程提供人工选择，不能保证算法始终正确。

本次未加入视频翻译、移动端、字幕编辑或新 TTS 产品线。长文的整批配置重绑定与生成前自动样音比较也不在此次完成声明内；继续复用既有逐段重做和参考对比。
