# WebUI 操作

[返回 README](../README.md) · [安装](INSTALL.md)

截图使用独立空白安装或合成测试数据，不含用户文件或真实录音。

界面语言会切换系统默认说明、处理进度和校验提示。录音文件名、人物命名、台词、转写及自行填写的授权记录保留原文，不自动翻译。

![语音生成工作台，浅色](images/studio-zh-CN.jpg)

## 找到功能

| 导航 | 用途 |
| --- | --- |
| 创作 | 语音生成、声音设计与音色库、批量配音、长文配音 |
| 制作 | 查看任务进度、试听审核、导出 |
| 资源 | 项目管理、管理与回收站、模型与系统 |

窄屏点击左上角菜单打开完整导航。声音工作区保留三个常用入口。

## 生成一句配音

1. 在「语音生成」填写文本，可选填作品名称、项目和配音语言。
2. 选择已有声音，或直接填写声音与演绎描述。没有参考录音也可以设计声音。
3. 需要多个版本或固定种子时，展开「生成选项」。已有参考时，可展开「参考与克隆」选择片段及模式。Hi-Fi 需要校对后的准确转写，不使用额外演绎描述。
4. 点击「开始生成」，到「任务队列」查看进度，再进入「试听与审核」。

语速、情绪和风格属于近似控制，生成成功不代表音频已经通过审核。

## 试听后导出

试听候选，点击「试听后批准」，确认听过并填写可选备注。可以批准后继续比较，也可以点击「批准并准备导出」。

勾选需要的音频，所选内容的对比、审核和导出操作才会出现。选中的音频全部通过审核后，可直接选择格式并点击「导出所选已审核音频」。下载链接会出现在同一页。需要采样率、声道、命名或草稿包时，进入「高级导出设置」。草稿带 DRAFT 标记，不改变审核状态。

「连续对比全部所选」会播放跨页或被筛选隐藏的所选音频，可随时停止。某个候选不合适时，点击「调整参考并重做」，选择参考片段、克隆模式和演绎说明。生成的新候选需要单独试听审核，原候选和审核记录保留。

## 创建和复用声音

声音区保留三个入口：「创建声音」「人物音色库」「参考片段库」。

- 创建声音：上传录音整理人物和片段，或选择文字设计。已有录音可直接处理，不必重复上传。
- 人物音色库：试听、编辑并复用人物，管理主参考与场景参考。
- 参考片段库：搜索、命名、标注和选择片段，直接设置人物并开始配音。

候选统一使用复选。保存后再决定创建人物、追加到已有的人物，或仅保留片段。新人物在此阶段选择默认参考。复合参考需要用户选择同人片段、通过检查并试听确认；自由试听合并不自动用于克隆。详见[参考整理与配音流程](WORKFLOW_GUIDE.md)。

## 批量和长文

多条台词使用「批量配音」，每行一条，提交前检查人物及内容预览。整本文件使用「长文配音」；已有作品优先显示，新导入入口可以展开。导入后检查章节与分段，先试生成一章，再继续全书。需要中止计算时点「暂停生成」，下次打开原作品续作。

长文在作品内逐章试听、审核和导出。作品的章节审核与普通候选列表分别管理，详见[长文配音](LONGFORM.md)。

先暂停作品，再点击某段的「调整参考并重做」。可试听人物的场景参考或片段库中的录音，只重做这一段。Hi-Fi 沿用参考演绎，需要准确转写；可控克隆可另填演绎说明，效果为近似控制。「版本记录与对比」保留成功旧版，可试听并采用。重做或采用旧版后，本章回到待审核，重新试听批准后再正式导出。

## 外观、快捷键和管理

右上角分别选择界面语言和配色；「跟随系统」使用浏览器或系统偏好。界面语言不改变配音语言。切换语言会刷新页面并保留文本草稿，文件和试听确认需重新选择。

| 操作 | 快捷键 |
| --- | --- |
| 搜索并跳转工作区 | Ctrl / ⌘ + K |
| 在语音生成页提交 | Ctrl / ⌘ + Enter |
| 切换声音工作区页签 | 左右方向键、Home、End |
| 关闭跳转或导航 | Esc |

已结束任务可手动归档或按设置自动归档。删除操作进入回收站，可恢复；归档和删除都不会立即清理原始文件。模型版本、安装路径和运行环境在「模型与系统」中按需展开查看。备份和停止服务见[维护说明](MAINTENANCE.md)。
