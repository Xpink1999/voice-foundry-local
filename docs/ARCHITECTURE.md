# 平台架构

日期：2026-10-22。平台独立于 Codex、游戏引擎及内容行业。安装根目录由本目录定位；所有运行路径由 config/platform.json 集中覆盖。

## 当前运行环境

- 主要验证环境为 Windows 11、RTX 4090。其他设备需要另行测试实际耗时与显存占用。
- 模型运行在独立 Python 3.11 venv，不修改系统 Python。
- 官方源码固定在 `cce58a5b59303c9bd63d12f23afe6a49a4a80c59`，vendor/VoxCPM 保留原始 Git 与 Apache-2.0 许可证。
- 官方 README 要求 Python 3.10–3.12、PyTorch >=2.5、CUDA >=12；VoxCPM2 支持设计、克隆、48kHz 和流式。实际性能另行测量，不引用宣传 RTF 作为本机验收。
- 官方 core.py：自然语言控制放在文本开头括号中；reference_wav_path 为音色参考，prompt_wav_path 与 prompt_text 为延续式克隆；optimize=False 可关闭 torch.compile。

## 模块与依赖方向

交互层（独立中文 WebUI、CLI、MCP）只访问 /api/v1。API 使用 FastAPI 与自动 OpenAPI；服务层拥有音色/项目/任务/审核/导出规则；SQLite WAL 保存事务数据；单工作线程从持久队列取任务；引擎注册表根据配置加载独立适配器。模型依赖只出现在引擎适配器内。第三方项目使用导出适配器，不依赖模型。

目录：

```text
voice-platform/
  config/platform.json      运行配置，路径相对安装根目录
  src/voice_platform/       API、任务、资产、音频、CLI、MCP、引擎与导出适配器
  web/                     独立静态中文界面
  scripts/                 安装、运行、维护与验收
  tests/                   核心契约和集成测试
  data/                    SQLite、参考音频、原始结果、导出与备份
  models/                  唯一模型权重目录及来源清单
  runtime/                 私有 Python、缓存、日志与进程信息
  vendor/VoxCPM/           固定官方源码
  docs/                    安装、API、维护、验收与证据
```

## 数据和安全契约

Voice UUID + 不可变版本快照；任务在提交时冻结音色版本、参考哈希、文本、参数、种子和模型修订。项目专属音色不能在其他项目使用；共享必须主动修改可见性。参考音频保存来源和授权记录；未知授权的参考不能用于正式生产。

候选默认 pending，人工试听后单独批准或拒绝。音色参考的确认与候选审核分开；正式导出只允许 approved。预览导出必须显式请求并标记为草稿。原始 WAV 永不被后处理覆盖。种子支持追踪和尽量复现，但不承诺跨 CUDA/依赖版本逐字节一致。

默认仅监听 127.0.0.1，不启用 CORS；校验 Host 与浏览器 Origin；远程监听必须配置环境变量中的鉴权令牌。上传受大小和音频解析限制。API 导出只写配置允许的根目录，外部项目通过 CLI 显式目标参数复制导出包；不扫描或修改已有游戏工程。

## 阶段与可观察完成条件

1. 环境：独立环境 CUDA 张量运行，真实 TTS/设计/使用合成自有参考的克隆和流式 WAV，记录模型与依赖版本。
2. 服务：真实 HTTP 异步生成、状态/结果、失败重试、取消、重启恢复、按需加载/卸载，原件和追踪清单可核验。
3. 界面：浏览器完成文本提交、任务查看、试听、波形、音色/项目管理、批量、候选审核、导出；人工听感认可单独记录。
4. 集成：全局 CLI、MCP 协议握手与工具调用；在不同 cwd 调用同一服务。注册全局配置前备份，保留无关项。
5. 适配：独立游戏资源示例与非游戏配音示例各导出一套可解析音频、清单、分段字幕；使用隔离样例目录。
6. 扩展：长文、候选版本、音色历史、能力驱动拒绝不支持的功能、第二个测试适配器验证契约、实际编码与后处理。

## 风险与处理

- Windows 原生依赖/编译：固定可运行的 CUDA wheel；默认关闭 torch.compile、降噪和可选文本规范化，保留官方源码。失败保存原始诊断。
- 模型首次下载较大：固定模型 revision；只下载一份所需权重；生成 SHA-256 清单。
- 显存共享：单队列限流，空闲自动卸载、手动释放；不终止其他软件占用。
- 音色漂移：复用已确认参考与冻结配置，长文分段用同一参考；不能承诺绝对一致。
- 语速/情绪/语气：自然语言近似控制，界面明确标示；不冒充精确滑杆。
- 字幕：基础时间戳来自真实分段音频长度，是分段级时间轴，不是词级强制对齐；精确对齐作为可选能力。
- 流式：保存增量 WAV 片段与事件，HTTP 消费事件与音频片段；取消在片段/分段边界生效，不承诺即时中断 GPU kernel。
- 授权：代码/权重许可证与参考声音权利分开记录；示范仅使用本机生成的虚构声音，不调用真人声音素材进行生产。
