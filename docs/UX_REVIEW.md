# 交互流程检查与改动

日期：2026-10-23。范围包括语音生成、声音设计与参考处理、音色库、项目、批量、任务、试听审核、导出、长文和回收站。

## 检查结果

主要问题集中在工作区之间的衔接、刷新后的上下文、选择范围和错误反馈。原有功能多数已经具备，但用户需要记住当前位置、自己找到下一步，也容易忽略列表之外仍被选中的内容。

| 环节 | 原有问题 | 本次处理 |
|---|---|---|
| 入口选择 | 短文本、批量和整本导入的关系不明确 | 生成页直接提供录音建音色、批量和长文入口 |
| 页面导航 | 刷新回到生成页，浏览器后退不能返回原位置 | 工作区、声音子页、任务详情、任务候选、长文章节和回收站范围使用地址栏位置；后退、前进和刷新可恢复 |
| 草稿 | 普通刷新会丢失文本和配置；恢复范围不清楚 | 同一标签页保存配音、批量、声音设计和长文导入草稿，含人物映射、筛选和结果选择；24 小时过期，可手动清除 |
| 未保存编辑 | 音色和设置被切走后容易丢失 | 设置保留未保存值并提供放弃操作；未保存音色切换和关闭有提示；文件、音色编辑和设置在离开页面前有丢失保护 |
| 生成提交 | 错误只在提示条短暂出现，重复提交缺少保护 | 错误保留在表单内；提交期间阻止重复提交；接口校验指出具体字段或台词序号 |
| 长文本入口 | 文件导入可能直接越过普通编辑框的字数限制；粘贴可能被截断 | 普通文件和过长粘贴转为明确的长文导入建议，保留待转交内容，不自动生成 |
| 音色库 | “管理音色”却进入上传页；保存后还要自己找人物 | 管理按钮进入人物库；保存后提供直接使用该音色配音的操作 |
| 单次参考 | 切换人物可能沿用上一个参考覆盖项 | 人物变化时重置本次覆盖；无参考或模型不支持时不可选择 Hi-Fi |
| 声音与音频处理 | 快速切换录音时，迟到响应可能覆盖当前详情 | 参考和处理详情核对当前对象；各类试听统一避免同时发声 |
| 项目 | 只有普通配音入口 | 项目卡片可进入普通、批量、长文或对应结果，并带入项目范围 |
| 批量输入 | 依赖 UUID，提交后才知道格式错误；JSON 的默认设置与表单不一致 | 可用人物名称或 ID，未识别角色可在预览中分配；逐条显示内容和音色，检查数量、项目隔离和 Hi-Fi 条件，统一应用默认设置 |
| 批量规模 | 大段错误输入可能阻塞解析 | 常规批量预览有长度保护；超过 200 条或过长文本引导到长文流程 |
| 任务 | 完成后需展开详情寻找结果；重试后仍停留原任务 | 完成行直接试听候选；重试打开新任务；保留原任务记录 |
| 结果选择 | 换项目、筛选或翻页后，选择范围不透明 | 显示所选音频清单与当前页外的数量；支持只看所选、清空和全选本页 |
| 审核 | 批量按钮的确认状态不直观；批准后可能被“待审核”筛选隐藏 | 未勾选人工试听确认时不能批准；批准并准备导出后显示所选音频，清除冲突筛选 |
| 连续对比 | 多次点击可能累积播放回调，无法明确停止 | 本页所选连续对比可停止；替换旧回调；离开工作区停止播放 |
| 导出 | 没有展示实际导出清单，未审核时到提交才报错 | 导出页展示所选音频和未审核数量；正式导出条件不满足时禁用，保留显式草稿选项；裁剪和字幕互斥 |
| 长文列表 | 大型导入表单挡在已有作品前面 | 已有作品优先展示，导入收起为“导入新作品”；空库默认展开 |
| 长文章节 | 选章后缺少下一步；审核和导出之间需要自己寻找 | 默认打开当前目录页中的待处理章节，显示剩余或失败段提示；完成后提示试听审核，批准后可导出本章并进入下一章 |
| 长文切换 | 旧请求可能刷新新作品或新章节 | 使用上下文序号丢弃旧响应；审核确认在章节或版本变化时清除 |
| 章节删除 | 假定章号连续会跳到已删除章节 | 下一章按有效章号查询，支持跳过已删除章节，不加载全书目录 |
| 列表规模 | 音色、项目、结果和导出一次渲染全部项目 | 音色、项目和结果每页 12 项，导出每页 20 项；任务、长文和回收站保留服务端分页 |
| 后台刷新 | 在无关工作区也重复读取全部目录 | 低频刷新音色等目录，写操作使缓存失效；非生产页降低普通结果读取频率，隐藏页暂停普通轮询 |
| 删除恢复 | 删除完成后需要再到回收站查找 | 原有引用预览保留，完成后可以直接撤销这一批删除；回收站类别、范围和视图可以恢复 |
| 键盘与语言 | 部分筛选缺少名称，声音子页没有键盘切换 | 补充筛选名称，声音子页支持方向键/Home/End；新流程文案同时维护中英日韩 |

## 本次没有改变的规则

文件不会自动提交到生成队列。生成成功、保存参考、算法推荐和试听确认分别处理。恢复草稿不会恢复访问令牌、文件选择、授权勾选或人工试听确认；恢复结果选择也不会改变审核状态。

删除仍为可恢复删除，原始音频和长文原件保留。正式导出仍由服务端验证审核状态。后台任务不依赖页面持续打开。

## 验证

自动检查包括完整 Python 回归、浏览器语言与配色检查，以及批量解析、项目隔离、类型错误、Hi-Fi 条件、编码、选择范围和地址栏恢复规则。测试配置明确从当前源码导入，避免误测其他安装目录的旧代码。

浏览器验收使用独立数据目录和测试引擎：实际提交批量、恢复草稿、保存并使用人物、隐藏选择提示、分页、审核拦截、删除与撤销、长文章节生成与恢复、导出条件、设置未保存值以及四种界面语言。正式用户库没有放入这些测试记录。

自动化检查为 68 项 Python 回归和 20 项前端规则检查。浏览器还验证了 67,200 字的 GB2312 文件从普通导入转入长文，拆成 3 章、421 段；保存的源文件与上传文件 SHA-256 一致，导入后没有自动生成。

具体运行结果与截图存放在本机 `runtime/ux-review/`，不作为开源源码分发。

## 验证范围

本次不重新评价真实模型的音质、说话人分离质量或人工听感；流程测试不能替代用户试听。当前桌面浏览器已检查深浅配色和四种语言，未做手机或触控设备验收。

目录接口仍保留现有的完整资产响应；本次减少无关请求并限制页面渲染数量。长文内容继续使用独立分页接口，不会将全书载入普通结果列表。资产达到很大规模时，后续应按实际响应耗时决定是否迁移普通目录接口，不能把本次桌面流程验证当成大规模性能结论。
