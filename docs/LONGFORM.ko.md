# 장문 음성 제작

‘제작 → 장문 음성 제작’을 엽니다. 기존 작품이 먼저 표시되며 새 가져오기 영역은 펼쳐서 엽니다. 목소리 설명과 복제 모드는 선택 설정입니다. 장 검토와 내보내기는 작품 안에서 진행합니다. 화면 안내는 [WebUI 사용법](WEBUI.ko.md)을 참고하세요.

## 가져오기와 분할

장문 음성 제작 화면에서 TXT 또는 Markdown을 가져오고 목소리와 프로젝트를 선택합니다. 목차와 구간을 확인한 뒤 전체 또는 선택한 장을 생성하세요. 브라우저를 닫아도 작업은 계속됩니다. 중단하려면 일시 정지를 사용합니다. 플랫폼을 다시 시작한 뒤에도 같은 작품을 열어 이어서 작업할 수 있으며 완료된 구간은 유지됩니다.

제목과 줄바꿈이 없어도 가져올 수 있습니다.

- 독립된 중국어 장·절 표제, Chapter 숫자·로마 숫자, 서장·후기와 Markdown 제목을 인식합니다.
- 제목이 없으면 문단과 약 30,000자 경계로 자동 장을 만듭니다. 이는 관리 단위이며 원래 책의 목차가 아닙니다.
- 문단도 없으면 문장 부호와 길이로 분할합니다. 기본 음성 구간은 최대 160자입니다. 정규화한 UTF-8 본문의 바이트 위치와 내용 해시를 기록합니다.
- 규칙 기반 인식이므로 특이한 제목, 목차, 머리글은 확인이 필요합니다. 잘못된 장이나 구간은 관리 화면에서 제외·복구하고 다시 검토할 수 있습니다.

자동 또는 UTF-8, UTF-16(BOM 유무와 명시적 바이트 순서 포함), GB2312, GBK, GB18030을 선택할 수 있습니다. 자동 모드는 BOM을 확인하고 전체를 UTF-8로 검증한 뒤 GB18030을 시도합니다. GB2312 파일도 사용한 디코더가 GB18030으로 표시될 수 있습니다. 디코딩 오류를 대체 문자로 숨기지 않으며 원본을 보존하므로 다른 인코딩으로 다시 시도할 수 있습니다.

## 저장과 한도

장문은 일반 60,000자 입력란이나 200개 항목의 일괄 API와 별도로 처리합니다. 책 전체를 수십만 개의 일반 작업으로 한 번에 만들지 않습니다. SQLite가 작품, 장, 구간, 시도를 색인화하고 화면은 페이지 단위로 읽습니다. 줄바꿈이 없는 긴 줄도 제한된 블록으로 분석하며 구간 색인은 1,000개마다 저장합니다.

원본 바이트는 `data/longform/<작품 UUID>/source.original`에 보관합니다. 줄바꿈을 통일한 UTF-8 사본은 따로 저장합니다. 두 파일의 SHA-256을 모두 기록하며 구간 위치는 정규화한 파일을 기준으로 합니다. 원본 GB2312·UTF-16의 바이트 위치와 다릅니다.

가져올 때 작품의 목소리 버전, 기본 참조와 전사문 버전, 모델, 매개변수, 기본 시드, 분할·쉼 설정을 고정합니다. 구간을 다시 생성할 때는 해당 구간의 참조와 표현 설정을 따로 저장할 수 있으며 작품 기본값은 바뀌지 않습니다. 기본 업로드 한도는 **원본 파일 2 GiB**이며 설정으로 변경할 수 있습니다. 모델에는 작은 구간씩 전달합니다. 실제 제작량은 디스크 공간, 실행 시간, 모델 능력에 따라 제한됩니다.

## 이어서 작업·재시도·다른 버전

일반 TTS와 오디오 처리와 모델·연산 잠금을 공유합니다. 구간마다 상태, 시도, 텍스트·오디오 해시, 모델, 참조 설정 해시, 실제 시드를 저장합니다. 작품·장·상태 색인으로 다음 구간을 찾으며 성공한 구간은 일반 큐에 다시 넣지 않습니다.

일시 정지나 재시작 시 미완료 구간은 대기로 돌아가고 성공한 파일과 기록은 남습니다. 한 구간이 실패하면 작품을 일시 정지합니다. 실패 구간을 재시도하거나 실패를 건너뛰고 나머지를 계속할 수 있습니다. 모델이나 참조 해시가 바뀌면 다른 조건으로 재개하는 것을 거부합니다.

### 참조를 조정해 한 구간만 다시 생성하기

먼저 작품을 일시 정지하고 진행 중인 내보내기를 완료하거나 취소하세요. 성공 또는 실패한 구간의 참조 조정·재생성을 열어 본문과 현재 음성을 확인합니다. 인물의 상황별 참조나 참조 클립 라이브러리에서 선택한 뒤, 참조 음성과 전사문을 확인하고 제어 가능한 복제의 표현 설명과 선택적인 시드를 설정할 수 있습니다. Hi-Fi는 정확한 전사문이 필요하며 참조의 표현을 따르므로 추가 스타일 설명을 사용하지 않습니다.

기본적으로 해당 구간에 고정된 참조와 설정을 이어받습니다. 인물의 기본 참조를 나중에 바꿔도 자동으로 반영하지 않습니다. 가져올 때의 참조와 설정으로 복원하는 항목을 선택하면 작품 기본값으로 돌아간 뒤 이번 변경을 지정할 수 있습니다. 한 구간만 다시 생성하면 해당 구간만 처리하며 장이나 책의 나머지 구간을 이어서 생성하지 않습니다. 다른 구간과 작품 기본값은 유지됩니다. 작품 전체의 목소리나 모델을 바꾸려면 별도 작품으로 가져오세요.

이전 음성과 시도 기록은 보존됩니다. 버전 기록에서 성공한 음성을 비교하고 이전 버전을 채택할 수 있습니다. 다시 생성하거나 이전 버전을 채택하면 해당 장은 검토 대기로 돌아갑니다. 정식 내보내기 전에 다시 듣고 승인해야 합니다. 실패 구간은 기존 설정으로 재시도할 수도 있습니다. 모델이나 고정된 참조 파일이 일치하지 않으면 새 조건으로 임의 변경하지 않고 생성을 거부합니다.

일반 재생·검토 화면의 후보도 참조 조정·재생성을 지원합니다. 검토 대기 상태의 새 후보를 만들며 원래 후보와 승인 상태는 바꾸지 않습니다. 장문 작품의 장별 검토, 진행 상황, 내보내기는 작품 안에서 관리합니다.

고정 참조는 변화를 줄이지만 책 전체의 목소리와 운율이 완전히 같아지는 것을 보장하지 않습니다. 중단이 반영되는 시점은 모델의 스트리밍·반환 경계에 따라 달라집니다.

## 장별 재생과 검토

장 안에서 연속 재생하거나 구간별로 들을 수 있습니다. 플레이어는 한 번에 한 구간만 읽습니다. 재생이 끝나도 청취 확인이나 승인을 자동으로 하지 않습니다.

승인하려면 해당 장의 모든 유효 구간이 성공해야 하며 사용자가 직접 들었음을 확인해야 합니다. 재생성, 제외, 복구로 바뀐 장은 검토 대기로 돌아가고 다른 장의 승인은 유지됩니다. 검토 이력은 `lf_reviews`에, 이전 음성은 시도별 폴더에 보관합니다.

## 내보내기

작품의 내보내기 화면에서 현재 장, 장별 파일, 책 전체 단일 파일을 선택합니다. WAV, FLAC, MP3, OGG는 모델 원본 샘플레이트를 사용하며 추가 인코딩은 로컬 FFmpeg로 처리합니다.

정식 내보내기에는 선택한 유효 장의 완료와 현재 음성 버전 승인이 필요합니다. 미검토 내용은 초안을 명시적으로 선택하세요. 오디오와 ZIP 이름에 DRAFT를 붙이고 매니페스트에 `draft=true`를 기록합니다. 일반 생성 결과의 승인 상태는 바꾸지 않습니다.

오디오와 ZIP64는 블록 단위로 기록합니다. RIFF 용량을 초과할 것으로 예상되는 WAV는 RF64를 사용합니다. 오래된 플레이어에서 지원하지 않으면 장별 파일이나 FLAC를 선택하세요. 전체 책 결합 시 중간 장별 WAV도 남기므로 추가 공간이 필요합니다. 책 전체 PCM을 메모리에서 합치지 않습니다.

설정 스냅샷, 원본 해시, 본문과 채택한 버전의 매개변수·오디오 해시를 포함한 `segments.jsonl`, `chapters.jsonl`, 구간 경계 자막, `generation-profiles.jsonl`을 포함합니다. 마지막 파일은 내보내기에 사용한 구간별 재정의 설정을 설정 해시별로 기록합니다. 각 take의 `generation_profile_id`로 연결되며, 재정의하지 않은 구간은 작품 스냅샷을 사용합니다. 장별 SRT는 0부터 시작하고 `book.srt`는 책 전체 시간축을 사용합니다. 단어 단위 정렬이 아닙니다.

내보내는 동안 해당 작품의 생성 변경을 잠급니다. 다른 작품과 일반 TTS는 사용할 수 있습니다. 취소·실패·중단 시에도 기록한 파일을 남기며 새 내보내기 작업으로 재시도할 수 있습니다. 구간 원본은 덮어쓰지 않습니다. 다운로드는 스트리밍 방식이고 CLI는 ZIP SHA-256을 검증합니다.

## 복제 모드

- `clone_mode=reference`: 참조 목소리와 선택적인 괄호 스타일 지시를 사용합니다. 속도, 감정, 표현은 근사적인 유도입니다.
- `clone_mode=hifi`: 같은 구간을 `reference_wav_path`와 `prompt_wav_path`로 전달하고 정확한 `prompt_text`를 제공합니다. 추가 스타일 없이 참조의 표현을 따릅니다.

작업대에서 참조의 전체 전사문을 수정·저장할 수 있습니다. 새 대사가 아니라 참조 녹음의 내용을 입력해야 합니다. 일반 작업대, 일괄 생성, 장문 가져오기에 모드 선택이 있습니다. 확인하지 않은 자동 전사문은 초안으로 남습니다. Hi-Fi라는 이름이 유사도나 청취 승인을 보장하지는 않습니다.

## 삭제와 복구

관리·휴지통에서는 프로젝트, 목소리와 버전, 참조와 녹음, 작업, 재생 결과, 내보내기, 처리, 비교, 장문 작품·장·구간·내보내기를 다룹니다. 단일·일괄 삭제, 연관 관계 미리보기, 선택 항목 또는 삭제 묶음 복구를 지원합니다.

삭제는 일상 목록에서 옮기는 동작입니다. 모델, 본문, 오디오, 추적 기록을 물리적으로 지우지 않아 공간이 확보되지는 않습니다. 실행 중인 작업은 먼저 멈추세요. 목소리에 연결된 참조는 해제하거나 목소리와 같은 묶음으로 삭제합니다. 현재 목소리 버전만 따로 삭제할 수 없습니다. 보호 항목이 하나라도 있으면 전체 묶음을 거부합니다.

작품 삭제 시 수많은 구간을 개별 휴지통 항목으로 펼치지 않습니다. 장을 삭제하면 같은 묶음에서 유효 구간을 제외합니다. 장 복구는 그 묶음에서 제외한 구간만 복구하며 이전에 개별 삭제한 구간은 되살리지 않습니다. 내용이 바뀐 장은 다시 검토해야 합니다.

일반 재생·검토 화면에서 여러 결과를 검토하고 내보내거나 확인 창에서 승인 후 내보내기를 준비할 수 있습니다. 고급 설정은 내보내기 센터에 있습니다. 청취 확인 없이는 승인할 수 없으며 미검토 결과가 섞여 있으면 정식 내보내기를 할 수 없습니다.

## CLI·MCP·API

예시는 선택 사항인 전역 CLI를 등록한 뒤 사용합니다. ID 문자열을 서비스가 반환한 ID로 바꾸고 필요한 명령만 실행하세요.

~~~powershell
$voiceId = "VOICE_ID"
$bookId = "BOOK_ID"
$exportId = "EXPORT_ID"
voice import-book .\book.txt --encoding auto --voice-id $voiceId
voice book $bookId --chapters
voice book-resume $bookId
voice book-pause $bookId
voice book-retry-failed $bookId
voice book-segments $bookId 1 --limit 25
voice book-export $bookId --mode chapters --draft
voice book-export-status $exportId
voice book-download $exportId --dest .\output
~~~

`voice delete-assets`는 `--apply`가 없으면 변경 내용을 미리 보여줍니다. 삭제 묶음 ID를 `voice restore-asset-batch`에 전달하면 묶음을 복구합니다.

REST 접두사는 `/api/v1/longform`과 `/api/v1/assets`입니다. 전체 계약은 실행 중인 서비스의 `/docs`에서 확인합니다. 구간 재생성, 이전 음성, 버전 채택 필드는 [API 안내](API.md#按参考重做)(중국어)에 있습니다. MCP는 가져오기, 페이지 조회, 재개, 내보내기, 에셋 관리를 제공하지만 사용자를 대신해 승인하는 도구는 없습니다. 업데이트 후 MCP에 재연결하세요. 모델 재설치는 필요하지 않습니다.

## 설정과 검증 범위

`config/platform.json`의 `longform`에서 `max_source_bytes`, `segment_chars`, `fallback_chapter_chars`, `import_batch_segments`, `pause_ms`, `block_frames`를 관리합니다. 변경은 새로 가져온 작품에 반영됩니다.

온라인 DB 백업은 장문 색인과 휴지통 메타데이터를 포함합니다. 전체 복구에는 `data/longform`과 다른 오디오 폴더도 필요합니다. 원본, 정규화 본문, 생성 시도, 내보내기를 보존하며 복구 불가능한 디스크 정리는 구현하지 않았습니다. 대용량 가져오기 테스트는 책 전체 생성이나 사람의 청취 검수를 뜻하지 않습니다. [검증 범위](TESTING.md)는 중국어입니다.
