# 참조 정리와 더빙 작업 흐름

## 녹음으로 목소리 만들기

1. 목소리 만들기에서 녹음을 업로드하고 이용 권한을 확인합니다. 각 원본은 따로 보관됩니다.
2. 화자 추적이 준비되어 있으면 화자 클립 정리로 진행합니다. 그렇지 않으면 원본 후보를 듣거나 화자 및 오디오 처리에서 분석을 시작합니다.
3. 화자별로 듣고 보관할 클립을 선택합니다. 선택 방식은 하나이며 재생, 마우스 이동, 포커스로 선택이 바뀌지 않습니다.
4. 클립을 개별 저장하거나 같은 화자의 클립으로 복합 참조를 만듭니다.
5. 이어서 목소리를 만들거나 기존 목소리에 추가합니다. 새 목소리의 기본 참조를 선택하며 기존 기본 참조는 유지됩니다.
6. 이 목소리로 더빙을 선택하면 작업대에 목소리가 설정됩니다. 대사만 입력하면 됩니다.

## 짧은 클립으로 복합 참조 만들기

사용자가 명시적으로 고른 동일 화자의 클립만 사용합니다. 한 사람의 모든 발화를 자동으로 합치지 않습니다. 원본 구간 중복, 권한, 출력별 발화 검출과 길이를 확인한 후 초안을 만듭니다. 기본 조건은 추정 발화 5초 이상, 간격을 포함한 전체 길이 30초 이하이며 `speaker_tracking`에서 설정합니다.

파일 길이와 추정 발화 시간은 다릅니다. 무음이나 중복 원본 구간으로 최소 발화 시간을 채울 수 없습니다. 합친 결과를 듣고 저장하세요. 최종 오디오를 다시 전사하지만 Hi-Fi 사용 전에 교정이 필요합니다. 저장만으로 자동 승인되지 않습니다.

시험 청취용 결합에는 다른 화자를 포함할 수 있지만 단일 화자의 참조로 저장할 수는 없습니다. 순서, 클립, 간격이 바뀌면 새 파일을 만들고 이전 버전을 보존합니다.

## 화자 수정과 트랙 비교

화자 지정 및 분석에서 화자 변경, 미지정 유지, 제외, 실행 취소를 할 수 있습니다. 이름과 화자 식별은 별개입니다. 수정 이력은 보관하며 이전 참조나 목소리 스냅샷을 덮어쓰지 않습니다. 파생 자료에는 출처 변경을 표시하고 이전 타임라인은 변경 전 버전으로 구분합니다.

단독 발화와 전체 화자 타임라인은 별도로 저장합니다. 전체 트랙은 구간별 원본 매핑으로 배치하며 지정된 중첩 분리 음성도 포함합니다. 미해결 구간은 원본에서 확인해야 합니다. 무음만으로 화자가 말하지 않았다고 판단할 수 없습니다. 발화 시간은 추정치이며 음성 유사도는 신원 확률이 아닙니다.

새 작업은 자동, 1, 2, 3인을 지원합니다. 자동 분석에서 3인을 초과하면 범위 초과로 표시하며 강제로 합치지 않습니다. 선택 모델 [SepFormer WSJ0-3Mix](https://huggingface.co/speechbrain/sepformer-wsj03mix)는 기본 8 kHz 3화자 모델입니다. 리샘플링은 고음을 복구하지 않으며 중국어 품질도 승인되지 않았습니다. 모델이 없으면 중첩 구간은 미해결로 남고 신뢰할 수 있는 단독 클립은 사용할 수 있습니다.

```powershell
.\.venv\Scripts\python.exe scripts/setup_three_speakers.py
```

먼저 화자 추적 환경을 설치하세요. 이 선택 단계는 모델 리비전과 해시를 기록하며 녹음을 전송하지 않습니다. 모델 로드 성공은 청취 품질 승인이 아닙니다.

## 검토, 수정, 내보내기

일반 후보와 장문 구간의 재생성 창에서 이번 대사와 참조를 수정할 수 있습니다. 원문, 원본 오디오, 이전 버전은 유지됩니다. 장문 수정은 해당 구간에만 적용되고 해당 장의 검토는 초기화됩니다. 이전 버전을 채택하면 그 버전의 제작 텍스트도 복원됩니다.

구간별 문제를 표시하고 작품 문제 목록에서 장과 페이지를 넘어 이동할 수 있습니다. 생성 성공은 수동 문제 표시를 지우지 않습니다. 해결 표시도 장을 자동 승인하지 않습니다. 일반 후보를 다시 열면 연결된 재생성 작업과 비교 결과를 복원하여 중복 생성하지 않습니다.

검토 화면은 검토 후 내보내는 순서로 동작합니다. 형식과 삭제 등은 추가 작업에 모았습니다. 일반 내보내기는 백그라운드에서 계속됩니다. 새로고침 후에도 내보내기 화면에서 기존 작업 조회, 취소, 재시도, 다운로드가 가능합니다. 검토 전 음성은 초안으로 명시하여 내보내야 합니다.

## 기존 데이터와 유지보수

업데이트 전에 서비스를 중지하고 데이터베이스와 설정을 백업하세요. 이벤트 순번 표와 문제 표를 추가하지만 기존 자료는 다시 쓰지 않습니다. 이전 결합은 시험 청취용, 이전 타임라인은 단독 발화용으로 유지합니다. 기록이 없는 측정값과 확인 상태는 알 수 없음으로 남습니다. 롤백할 때는 중지 후 일치하는 데이터베이스, 설정, 소스를 함께 복원하세요. 표만 개별 삭제하지 마세요.

파일 설치 상태와 모델 로드 상태는 구분합니다. 파일이 없으면 초안을 유지하고 설치 경로를 안내합니다. 이벤트 재전송이 오디오의 임의 위치에서 추론을 재개한다는 뜻은 아닙니다.

## 작업 공간 간 이동

작업대에서 일괄 더빙이나 장문으로 이동하면 현재 대사, 프로젝트, 인물, 참조, 복제 모드와 연기 설정을 가져옵니다. ‘참조 및 생성 설정’에서 참조, 엔진, 언어와 시드를 확인하세요. 제출하지 않은 초안이 있으면 교체 전에 확인합니다. 작품에는 기본 인물 한 명을 지정하며 일괄 역할 배정을 하나의 목소리로 바꾸지 않습니다.

일괄 역할은 해당 행의 프로젝트에서 사용할 수 있고 보관되지 않은 인물만 자동 연결합니다. 일치하는 인물이 없으면 직접 선택할 수 있습니다. 다른 인물은 각자의 기본 참조를 사용하며 JSON에서 명시한 참조는 유지됩니다. 제출 후 해당 배치의 작업 목록으로 이동하고 후보 듣기로 이어갈 수 있습니다. 배치 작업과 검토 범위는 URL로 복원됩니다.

프로젝트나 작업에서 후보를 열면 이전 필터를 지우고 명시적으로 선택한 항목과 숨겨진 선택 수를 유지합니다. 내보내기 기록을 프로젝트, 제목, 파일 이름으로 검색하고 내용 목록을 펼치거나 남아 있는 원본 후보로 돌아갈 수 있습니다. 삭제된 원본은 사용할 수 없다고 표시됩니다. 새로 고쳐도 변경되지 않은 선택 상세는 펼쳐진 상태를 유지합니다.

모델이 없으면 일괄 제출, 장문 이어서 생성, 재생성 전에 이유를 표시합니다. 기존 음성의 듣기와 내보내기는 계속 사용할 수 있습니다.
