# 参考整理与配音流程

## 从录音创建人物

1. 在「创建声音」上传录音并确认用途授权。每份录音独立保留。
2. 人物跟踪可用时，打开「继续整理人物」。否则先试听原声候选；人物整理可从「人物与音频处理」启动。
3. 逐人试听，勾选要保留的片段。每张卡只有一套选择；试听、焦点和鼠标经过不会改变勾选。
4. 选择「分别保存片段」，或为同一个人选择「创建复合参考」。
5. 保存后直接创建人物或添加到已有的人物。新人物明确选择默认参考；已有默认参考保持不变。
6. 点击「用此人物配音」，人物和参考会带入工作台，只需填写台词。

## 短片段组成参考

复合参考是用户明确选择的同人片段，不会自动把整个人物的讲话拼在一起。检查来源重叠、授权、独立人声检测和时长后，先创建草稿。默认至少 5 秒有效人声、最多 30 秒总长，含片段间隔；阈值在 `speaker_tracking` 配置中。

文件时长和有效人声估计分开。重复源区间不重复计时，也不能作为两份内容凑时长。静音不用于凑时长。试听合并结果并确认人物一致后，保存到参考库。转写由最终音频重新识别，仍需人工校对；Hi-Fi 模式沿用现有转写确认要求。新参考与新配音均不会自动批准。

「仅合并试听」允许自由组合，不能直接当单人参考。更换顺序、片段或间隔会产生新文件；旧文件不覆盖。

## 人物归属与音轨

展开片段的「人物归属与检测详情」，可重新归属、保持未知、排除或撤销上次修改。人物名称与身份分开。纠正保存历史；旧参考和音色快照不改写，派生成品会标记来源已变。旧时间轴标为修改前版本。

独白时间轴和完整人物时间轴分开保存。完整轨按每段映射恢复原始停顿，包含已归属的重叠分离语音；未解决区域仍需对照原件，不能据静音判断人物没有讲话。有效人声为模型估计，声纹相似度不是身份概率。

新任务人数为自动、1、2、3。四人及以上的自动结果明确超范围，不强并人物。三人重叠的可选候选是 [SepFormer WSJ0-3Mix](https://huggingface.co/speechbrain/sepformer-wsj03mix)，原生 8 kHz，不能宣称高频恢复或中文效果已通过。未安装时保持未解决，不影响可靠独白片段。

```powershell
.\.venv\Scripts\python.exe scripts/setup_three_speakers.py
```

先安装人物跟踪环境，再按需安装此候选。该步骤下载模型并记录修订与哈希，不上传录音。模型可加载不等于试听验收通过。

## 试听、修正与导出

普通候选和长文分段的重做窗口都可编辑本次台词、换参考并重新生成。原文、原音频与旧版本保留。长文修改仅影响本段，所属章节需重新审核；采用旧版本也会恢复对应生产文本。

长文可逐段「标记问题」，在「作品问题清单」跨章定位，包括分页后的分段。生成成功不会清除人工问题；明确解决后，仍需重新试听审核。普通重做的任务关联原候选，关闭窗口后重新打开可恢复进度与新版对比。

审核区按当前状态显示下一步：先审核，通过后导出。格式、删除和其他设置放在「更多操作」。普通导出在后台执行，刷新后在导出中心查看原任务、取消、重试或下载，不需要重新打包。未审核内容只能显式导出为草稿。

## 旧数据与维护

升级前停止服务并备份数据库与配置。新增事件序号表和问题表；原实体、录音与旧音轨不重写。历史合并默认仍为试听，旧时间轴仍为独白轨，缺失的检测和确认字段保持未知。若需回滚，停止服务后恢复成套备份和对应源码，不单独删表。

语音引擎就绪检查区分「已安装」和「已加载」，缺文件时保留草稿并显示安装入口。事件支持任务游标追赶；这不代表推理能从任意音频位置续跑。
